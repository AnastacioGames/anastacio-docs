Classe base: [`SCA_IActuator`](../sca_iactuator/)



Steering Actuator for navigation.

### behavior

The steering behavior to use.

**Tipo:** one of `these constants`

### velocity

Velocity magnitude

**Tipo:** float

### acceleration

Max acceleration

**Tipo:** float

### turnspeed

Max turn speed

**Tipo:** float

### distance

Relax distance

**Tipo:** float

### target

Target object

**Tipo:** `KX_GameObject`

### navmesh

Navigation mesh

**Tipo:** `KX_GameObject`

### selfterminated

Terminate when target is reached

**Tipo:** boolean

### enableVisualization

Enable debug visualization

**Tipo:** boolean

### pathUpdatePeriod

Path update period

**Tipo:** int

### path

Path point list.

**Tipo:** list of `mathutils.Vector`
