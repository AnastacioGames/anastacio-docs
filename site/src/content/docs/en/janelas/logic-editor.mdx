<p class="mag-kicker">Logic Editor</p>
<h2 class="mag-title">Game logic without writing code</h2>
<p class="mag-lede">Sensors detect, controllers decide, actuators act. The Logic Editor puts all of this into bricks that you connect with the mouse. In this issue, four Anastacio additions make this window easier to understand and to fix.</p>
<div class="mag-flow"><span>Sensor</span><b>→</b><span>Controller</span><b>→</b><span>Actuator</span></div>

<p class="mag-tag">New · Sidebar</p>
<h3 class="mag-h">Brick Inspector</h3>
<p class="mag-big">It points out errors before you press Play.</p>
<p>It checks the object's bricks and points out what is wrong or missing: key not chosen, empty script, brick with no connection, sensor with zero range, Add Object with the object on a visible layer, and others. Clicking the brick's name takes you straight to it.</p>
<ul class="mag-list">
<li><strong>Viewport</strong> draws in the scene the range of Near, Radar and Ray, and the target of Steering and Track To.</li>
<li><strong>Show Tips</strong> also shows the light tips.</li>
<li><strong>Other objects</strong> lists other objects in the scene that have problems.</li>
</ul>
</div>
<figure class="mag-side"><img src="/anastacio-docs/janelas/logic-editor/inspector.webp" alt="Brick Inspector listing problems" /><figcaption>Errors with a triangle, tips with an "i".</figcaption></figure>

<div class="mag-grid">
<article class="mag-card">
<p class="mag-tag">New · Top bar</p>
<h3 class="mag-h">Highlight Active</h3>
<p>With the game running, it lights up the bricks that are firing. You see the logic working live and quickly find the brick that does not react.</p>
</article>
<article class="mag-card">
<p class="mag-tag">New · Top bar</p>
<h3 class="mag-h">Convert to Python</h3>
<p>Turns the object's bricks into a Python script (<a href="/anastacio-docs/en/guias/smart-components/">Smart Component</a>). It is a good starting point when the logic grows too big to be done with bricks alone.</p>
</article>
<article class="mag-card">
<p class="mag-tag">New · Sidebar</p>
<h3 class="mag-h">Brick Groups</h3>
<p>Organizes the bricks into named groups, such as "Movement" or "Shooting". Renaming a group by double-clicking it also renames its bricks.</p>
</article>
</div>

<blockquote class="mag-quote">“Build the logic, open the Inspector, fix what it points out, and only then press Play.”</blockquote>

<section class="mag-classics">
<h3 class="mag-section">Also in this window</h3>
<div class="mag-cols">
<p><strong>Add.</strong> Menu for creating sensors, controllers and actuators.</p>
<p><strong>Properties.</strong> The object's variables: name, type and value. The <b>i</b> button shows the value on screen during play. On text objects, the <b>Text</b> property sets what is written.</p>
<p><strong>States.</strong> The object's 30 states. <b>Visible</b> shows or hides the bricks of each state, and <b>Initial</b> chooses which states the game starts with.</p>
<p><strong>Shortcut.</strong> The <b>N</b> key opens and closes the sidebar, where Properties, Brick Groups, States and Brick Inspector are.</p>
</div>
