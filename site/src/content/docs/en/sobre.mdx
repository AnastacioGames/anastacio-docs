Anastacio Engine started as a set of improvements to Range Engine 1.6 rev 1, made for my game, Rolima Racer (a soapbox cart racer).

<ol class="ae-tl">
<li><strong>The starting point</strong>The Range team was focused on version 2.0, which wouldn't be compatible with Rolima Racer. So I started making small improvements to 1.6.</li>
<li><strong>The results showed up</strong>The improvements worked so well that the custom version kept growing beyond what was planned.</li>
<li><strong>A real fork</strong>With so many changes, the best path was to turn the project into its own fork, with the mission of keeping the game improving.</li>
</ol>
