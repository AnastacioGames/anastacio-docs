Большая сцена долго открывается, потому что движок конвертирует каждый объект до первого кадра. В Anastacio для этого есть два инструмента:

- **Load Mode**: определяет, какие объекты загружаются вместе со сценой, а какие ждут.
- **Cook**: сохраняет в файл `.cooked` то, что вычисляет конвертация (физику, меши, шейдеры), чтобы не вычислять это повторно.

## Load Mode

Выберите объект и откройте **Properties > Object**, панель **Load Object with Scene**. Есть три режима:

| Режим | Что происходит |
|---|---|
| **With Scene** | По умолчанию. Объект создаётся вместе со сценой. |
| **On Demand** | Пропускается при загрузке. Создаётся, когда его запросит скрипт или когда Add Object впервые его использует. |
| **Editor Only** | Никогда не попадает в игру. Подходит для референсов, рабочих камер, блокаута. |

Режим применяется к выбранным объектам и их потомкам.

### Создание объекта On Demand из скрипта

(`cena` = сцена, `chefe` = босс, `tiro` = выстрел, `arma` = оружие: код тот же, что проверен на португальской странице.)

```python
import Range

cena = Range.logic.getCurrentScene()
chefe = cena.convertObject("Chefe")
```

Если `Chefe` находится на активном слое, он появляется в сцене. Если на неактивном — попадает в `objectsInactive` и готов для `addObject`:

```python
cena.convertObject("Tiro")
tiro = cena.addObject("Tiro", cena.objects["Arma"], 120)
```

`cena.unconvertedObjects` перечисляет имена, которые ещё можно создать таким способом.

### С Logic Bricks

Актуатор **Add Object** уже понимает On Demand: объект создаётся при первом срабатывании актуатора, а дальше только копируется. Скрипт не нужен.

## Cook

Кнопка **Cook** находится в панели Render и рядом с Play в заголовке. Она один раз запускает сцену и записывает рядом с `.blend` файл `.cooked`, содержащий:

- уже вычисленные формы столкновений (Convex Hull и Triangle Mesh);
- буферы мешей, нормали и тангенты;
- шейдеры, скомпилированные под вашу видеокарту.

При следующей загрузке движок читает файл вместо вычислений. В тестах загрузка сцены сократилась примерно с 2,4 с до менее чем 0,5 с.

- `.blend` должен быть сохранён (без сохранённого файла кнопка неактивна).
- **Clear Cooked** удаляет кэш. При изменении меша очищать его не нужно: изменённая часть пересчитывается.
- В экспортированной игре `.cooked` идёт вместе с ней. Шейдеры сохраняются на компьютере игрока при первом запуске, во время которого показывается экран подготовки.

## Измерение

`Range.logic.getLoadLog()` показывает, сколько длился каждый этап загрузки. Используйте до и после Cook, чтобы увидеть выигрыш.

```python
import Range

for etapa in Range.logic.getLoadLog():
    print(etapa)
```
