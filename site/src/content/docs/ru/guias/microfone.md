Движок записывает голос в редакторе и слушает микрофон во время игры. Это работает на ПК, в Web и на Android.

## Запись в редакторе

Кнопка **Record** находится на верхней панели. Один клик запускает запись сразу в Sequencer. Во время записи кнопка становится красной и показывает время и громкость.

Рядом с кнопкой есть такие команды:

- **Record New Sound**: записывает новый звук, не помещая его в Sequencer.
- **Select Microphone**: выбор микрофона.
- **Adjust Sound**: обрезка, фейды, нормализация и голосовые эффекты с сохранением в новый WAV.
- **Open Video Sequencer Window**: открывает Sequencer в отдельном окне.

Кнопка записи есть и там, где звук используется: в реплике катсцены, в ноде Sound в Logic Tree и на звуковых стрипах Sequencer.

## Использование в игре без кода

**Сенсор Microphone**

| Режим | Когда срабатывает |
|---|---|
| **Talking** | Пока голос выше порога. Остаётся включённым ещё **Hold** секунд. |
| **Shout / Clap** | Один импульс, когда громкий звук превышает порог (хлопок, крик, дуновение). |
| **Silence** | После **Hold** секунд ниже порога. |

**Актуатор Voice**

| Режим | Что делает |
|---|---|
| **Record** | Записывает, пока сенсор включён, или до **Max Seconds**. |
| **Play Recording** | Воспроизводит запись с эффектом. |
| **Live** | Воспроизводит микрофон с эффектом, пока сенсор включён. |
| **Stop** | Останавливает живой голос. |
| **Save WAV** | Сохраняет запись как `<имя>.wav` в папке игры. |

В Logic Tree используйте ноды **When Talking** и **Voice**. В UI Tree есть **Microphone Meter** и **Enable Microphone**.

## Голосовые эффекты

`NONE`, `CHIPMUNK` (высокий), `GIANT` (низкий), `ROBOT`, `RADIO`, `ECHO`, `CAVE` и `REVERSE` (только для записей).

:::caution
В живом режиме используйте наушники: колонки создают обратную связь с микрофоном.
:::

## Использование из Python

```python
import Range

# Включить микрофон (в Web — после клика или касания).
if Range.audio.microphoneState() == "closed":
    Range.audio.microphoneStart()

# Открывать рот персонажа по громкости голоса.
own["mouth"] = Range.audio.microphoneLevel()

# Записать, остановить и воспроизвести с эффектом.
Range.audio.microphoneRecordStart()
Range.audio.microphoneRecordStop("taunt")
Range.audio.playVoice("taunt", effect="ROBOT", reverb=True)
```

В примере `own` — объект вашего скрипта. Полный список: [`Range.audio`](../../api/modulos/audio/), [`KX_MicrophoneSensor`](../../api/types/kx_microphonesensor/) и [`KX_VoiceActuator`](../../api/types/kx_voiceactuator/).

## Web и Android

На панели экспорта Web у параметра **Microphone** есть значения **Auto**, **On** и **Off**. **Auto** включает его, когда игра использует микрофон.

- **Web:** браузер запрашивает разрешение у игрока. Микрофон запускается после первого касания или клика и требует `https` (или `localhost`).
- **Android:** APK запрашивает `RECORD_AUDIO`, только если пакет экспортирован с микрофоном.
