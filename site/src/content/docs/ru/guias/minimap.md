**Minimap** — это нода HUD в [UI Tree](../ui-tree/). Она не перерисовывает сцену, а показывает изображение карты, поэтому почти ничего не стоит.

## Создание одной командой

1. Сохраните `.range`. **Add > Minimap** с Bake и **Bake Map Image** не работают со сценой, которая ни разу не сохранялась.
2. В 3D View выберите игрока и используйте **Add > Minimap**.
3. Выберите стиль: **Radar** (вращающийся круг), **Whole Map** (неподвижный квадрат) или **GPS 3D** (наклонный прямоугольник).

Команда создаёт HUD, ноду, следующую за объектом, изображение карты и логику UI.

## Отметка объектов

Выберите объект и откройте вкладку **Object**, панель **Minimap**. Включите **Show on Minimap**. **Own Color** задаёт собственный цвет; без него используется цвет **Markers** ноды.

В скрипте цвет хранится в `minimap_color` в формате `#rrggbb`:

```python
own["minimap_color"] = "#ff3030"
```

Без панели используйте игровое свойство `minimap` или **Marker Prefix** в имени объекта. Маркеры за пределами области прижимаются к краю.

## Настройки ноды

| Параметр | Что делает |
|---|---|
| **World Min / Max** | Область мира, покрытая изображением. **Fit to Scene** измеряет её сама. |
| **Zoom Radius** | `0` показывает всю карту неподвижно; больше 0 — следует за игроком. |
| **Rotate with Player** | Вращает карту вместе с игроком. |
| **Camera Tilt** | Наклоняет вид от 0 до 60°, как 3D GPS. |
| **Shape** | Circle, Square, Rectangle или Ellipse. |
| **Border Style** | None, Solid или Soft. |

**Bake Map Image** делает снимок видимых мешей сверху, сохраняет `<файл>_minimap.png` рядом с `.range` и задаёт World Min/Max.
