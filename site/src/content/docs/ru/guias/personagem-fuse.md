Движок превращает OBJ персонажа из Fuse в готового для игры персонажа без использования Mixamo.

## Импорт

Откройте **File > Import > Fuse Character (.obj)**, выберите файл и настройте:

| Параметр | Что делает |
|---|---|
| **Skeleton** | Скелет из библиотеки, используемый как основа. |
| **Name** | Имя персонажа; группа называется `Group<Имя>`. Если пусто, берётся имя файла. |
| **Ragdoll** | Добавляет боксы ragdoll на большие кости, без кистей и пальцев. |
| **Output Folder** | Куда записываются `Group<Имя>.range` и `textures/`. Если пусто, создаётся папка рядом с открытым файлом. |
| **Game Folder** | Корень проекта игры для подключения компонента ragdoll. Если пусто, берётся папка открытого файла. |
| **Add to Scene** | Помещает готовую группу в текущую сцену, в 3D-курсор. |

Обработка идёт в фоне и не затрагивает открытый файл.

## Результат

- Тело уменьшено до 9000 треугольников на уровне 0 с сохранением головы и груди.
- LOD: 2500 треугольников на 10 м и 900 треугольников на 25 м.
- Группа с арматурой, телом и ragdoll, сохранённая для загрузки через `LibLoad`.

:::caution
Перед распространением игры проверьте лицензию мешей Fuse.
:::
