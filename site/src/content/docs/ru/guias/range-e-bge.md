---
title: Range и bge
description: Два имени главного модуля и почему Range пишется с заглавной R.
---

API движка находится в модуле **`Range`**, с **заглавной R**. Range Engine выбрал заглавную букву, чтобы модуль не путали с функцией Python `range()`.

```python
import Range
from Range import logic, events
```

Старое имя **`bge`** тоже работает. Движок регистрирует каждый подмодуль под обоими именами, поэтому `Range.logic` и `bge.logic` — один и тот же объект:

```python
import bge
from bge import logic
```

В этой документации во всех примерах используется `Range`.

| Range | bge | Для чего |
|---|---|---|
| `Range.logic` | `bge.logic` | Сцена, объекты, время, глобальные свойства и загрузка файлов |
| `Range.types` | `bge.types` | Классы игровых объектов: объекты, камеры, источники света, сенсоры, актуаторы |
| `Range.render` | `bge.render` | Окно, разрешение, VSync, курсор мыши и отладочная отрисовка |
| `Range.events` | `bge.events` | Константы клавиш, кнопок мыши и состояний ввода |
| `Range.constraints` | `bge.constraints` | Физические соединения, транспорт и настройки физического движка |
| `Range.application` | `bge.application` | Информация о приложении: версия, платформа |
| `Range.texture` | `bge.texture` | Динамические текстуры: видео, изображение, камера и рендер в текстуру |
| `Range.imgui` | `bge.imgui` | Окна и элементы интерфейса для отладки |
| `Range.network` | `bge.network` | Мультиплеер: соединение, сообщения и репликация объектов |

:::caution[Экспорт в Web]
Валидатор Web выдаёт предупреждение `WEB-PY-001`, когда находит `import bge`, и предлагает заменить его на `import Range`.
:::
